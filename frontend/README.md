# DoDigital Tech – Full Stack Marketing Platform

## Overview
DoDigital Tech is a full-stack digital marketing platform for small businesses.
It allows businesses to:
- Get instant website & delivery service quotes
- Schedule strategy calls
- Submit requests through a real backend API

## Tech Stack
- Frontend: React + Vite
- Backend: Express.js + Node.js
- Database: MongoDB Atlas
- Routing: React Router
- Styling: Basic CSS (minimal)

## Key Features
- Full frontend ↔ backend communication
- Dynamic pricing logic
- MongoDB persistence for quotes & meetings
- RESTful API design
- CORS-enabled backend
